SHORTSCOPE プライバシーポリシー

制定日：2026年8月7日
株式会社ラナン

株式会社ラナン（以下「当社」）は、当社が提供するショート動画市場分析サービス「SHORTSCOPE」（以下「本サービス」）における利用者の情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 取得する情報

  • アカウント情報：本サービスの利用に際して当社が発行するログイン情報、ワークスペース名、通知先（メールアドレス、Slack/Chatwork Webhook URL）等
  • 連携アカウント情報：利用者の同意に基づき、Google（YouTube）およびMeta（Instagram等）のAPIを通じて取得する、連携アカウントの統計情報（登録者数・再生数・エンゲージメント等）
  • 公開コンテンツ情報：YouTube Data API、Instagram Graph API等を通じて取得する、一般に公開されている投稿のメタデータ（タイトル、投稿日、公開指標、サムネイル画像URL等）
  • 利用状況情報：本サービスの操作ログ、アクセスログ等

2. 利用目的

  • 本サービスの提供・運営・品質向上（市場トレンド分析、競合分析、レポート生成等の機能提供）
  • 利用者からの問い合わせへの対応
  • 不正利用の防止、障害対応

3. 外部APIの利用

本サービスは以下の外部APIを利用します。取得した情報は各プラットフォームの利用規約・開発者ポリシーに従って取り扱います。

  • YouTube Data API / YouTube Analytics API（Google LLC）：本サービスは YouTube利用規約 および Googleプライバシーポリシー に従います。Googleアカウント連携は利用者がGoogleのセキュリティ設定ページからいつでも取り消せます。
  • Instagram Graph API / Meta oEmbed（Meta Platforms, Inc.）：公開投稿のメタデータおよび埋め込み情報（サムネイル等）の取得に利用します。
  • Anthropic API（Anthropic PBC）：分析コメントの自動生成に利用します。

4. 第三者提供

当社は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。

5. データの保存と削除

取得した情報は適切な安全管理措置のもとで保管します。利用者は、当社への連絡により、連携の解除および保存データの削除を請求できます。連携アカウントのアクセストークンは、連携解除時に破棄されます。

6. Cookie等の利用

本サービスは、ログイン状態の維持および利用状況の把握のためにCookieおよび類似技術を利用することがあります。

7. ポリシーの変更

本ポリシーの内容は、法令の変更または本サービスの機能追加に応じて改定されることがあります。重要な変更は本サービス上で告知します。
